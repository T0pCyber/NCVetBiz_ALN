# 4. Write the Process Down

**Use** on any task you repeat every week. This is how a prompt becomes a system.

```text
I do this task about [number] times a week: [describe the task].
Interview me one question at a time to capture the exact steps, the inputs I
need, the decisions I make, and what "done" looks like. When we finish, give me
a numbered checklist and mark which steps a tool could do for me and which ones
need my judgment.
```

> **Tip:** start with one annoying task. Not an AI strategy. One task. When it works, pick the next one.
